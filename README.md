# THE WORLD IN ONE DAY — Thursday 19 November 2026

A clean, hero-led newspaper front page that sums up Thursday 19 November 2026's world news in one 1024x1024 image. Forty verified stories are rendered programmatically with Python and PIL: a wide Shenzhen summit hero, two large cards for GTA VI's launch and Anthropic's record IPO, ten secondary cards with small original drawings, a dotted world map with numbered pins, and 27 numbered briefs — plus a by-the-numbers strip, an honest region-count bar, a date-check box separating Wednesday's news, and full source attribution.
